# Provenance & Source / License Record

This document records the origin, licensing status, and role of external
materials used in the **Synaptic Plasticity as Short-Term Memory** project.

The project is an educational interactive experiment built around a small,
deterministic toy model of activity-dependent synaptic state.

The project does not use an external training dataset.

directly by the application.

### Runtime Data

The RED, LEMON, APPLE, cue activations, synaptic states, and other values

## 4. Model Weights

The project does not ship or depend on pretrained neural-network weights.

There is no external LLM, image model, classifier, or other pretrained
model required to run the interactive experiment.

The `W` matrix used by the toy simulation is a project-level model variable
representing relatively stable prior connection state.

It is not a pretrained BDH checkpoint or model weight file.

## 8. BDH Relationship

This project is inspired by the concept of synaptic plasticity as a
temporary computational state in the Dragon Hatchling (BDH).

It is **not an official BDH implementation**.

It does not reproduce:

- the complete BDH neuron interaction graph;
- the complete BDH training procedure;
- the complete BDH inference mechanism;
- the complete BDH architecture;
- BDH's full scale or parameterization;
- all biological mechanisms discussed in the BDH literature.

The RED → LEMON experiment is deliberately much smaller.

Its purpose is to make one mechanism observable:

    recent activity
          ↓
    temporary synaptic change
          ↓
    altered prediction
          ↓
    decay of temporary state

## 9. Educational Model Equations

The project uses the following simplified representation:

    G = W + F

where:

- `W` represents relatively stable connection state;
- `F` represents temporary activity-dependent synaptic state;
- `G` represents the effective connection used by the toy model.

The toy update is:

    F(t+1) = γ · (x ⊗ h) + (1 − λ) · F(t)

with:

    F(0) = 0

These equations are part of the project's educational model.

They are **not claimed to be the complete equations of BDH or of
biological synapses**.
